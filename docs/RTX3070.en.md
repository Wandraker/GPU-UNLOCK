# RTX 3070: tensor-core unlock on Windows — step-by-step guide

[Русский](RTX3070.ru.md) · [README](../README.md)

Written from a real run on a Zotac RTX 3070 + Gigabyte B460M. Expect 1–2 hours, mostly installing tools.

## 0. Does your machine fit?

| Requirement | How to check |
|---|---|
| **RTX 3070, device ID `2484`** | PowerShell: `Get-PnpDevice -Class Display -PresentOnly \| Select InstanceId` must show `DEV_2484`. LHR (`DEV_2488`) is **not** admitted. |
| Exactly one NVIDIA GPU | At most one integrated GPU is fine. |
| UEFI boot, **CSM disabled** | BIOS → Boot. |
| **Secure Boot disabled** | BIOS, or `msinfo32` → Secure Boot State. |
| A spare USB stick | Formatted **FAT32**. |

If BitLocker is on, have your recovery key ready.

## 1. Tools

```powershell
winget install --id LLVM.LLVM --version 20.1.8 --exact
winget install --id Microsoft.VisualStudio.2022.BuildTools --exact --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install --id Python.Python.3.13 --exact
winget install --id Git.Git --exact
wsl --install -d Ubuntu-24.04
```

LLVM must be exactly **20.1.8**.

## 2. Clone

```powershell
git clone https://github.com/Wandraker/GPU-UNLOCK C:\gpu-unlock\GPU-UNLOCK
```

## 3. Generate the firmware assets (WSL)

The five NVIDIA firmware files cannot be redistributed. Everyone generates them from the official driver. In **Ubuntu**:

```bash
sudo apt-get update && sudo apt-get install -y git make tar zstd curl
curl -LsSf https://astral.sh/uv/install.sh | sh && ~/.local/bin/uv python install 3.14
sudo ln -sf ~/.local/bin/python3.14 /usr/local/bin/python3.14

cd ~ && git clone https://github.com/Zagitta/gpu-unlock.git fw && cd fw
git checkout --detach 0ebdb1c6308b6a2072be5bf04513472942541956
make inputs firmware PYTHON=python3.14 INPUTS=~/fw/inputs ASSETS=~/fw/assets
mkdir -p /mnt/c/gpu-unlock/assets && cp ~/fw/assets/*.bin ~/fw/assets/NVIDIA-LICENSE /mnt/c/gpu-unlock/assets/
```

Every file is hash-checked; the Windows build refuses mismatches.

## 4. Disable Fast Startup

Admin PowerShell: `powercfg /h off`. The unlock only runs from a GPU in its power-on state.

## 5. Read-only probe — two captures

Plug in the FAT32 stick (say `D`) and get the Windows ESP GUID: `(Get-Partition | Where-Object IsSystem).Guid`.

> **Windows PowerShell 5.1 note:** run the repo scripts as a separate process (`powershell -File ...`) as shown.
> Redirecting with `2>&1` / `*>` makes 5.1 treat Python's test progress on stderr as an error and abort.

```powershell
cd C:\gpu-unlock\GPU-UNLOCK
powershell -NoProfile -ExecutionPolicy Bypass -File .\research\profile\new-machine.ps1 -Drive D -WindowsEspGuid YOUR-GUID -Assets C:\gpu-unlock\assets -Clang "C:\Program Files\LLVM\bin\clang.exe" -LldLink "C:\Program Files\LLVM\bin\lld-link.exe"
```

This stages a **read-only probe**: it never writes to the GPU. Twice: **Shut down** (not restart), power on, open the firmware boot menu (Gigabyte F12, ASUS F8, MSI F11), pick the `UEFI:` USB entry, let Windows start.

## 6. Profile, host tests, package

Run the **same command** again. It generates your machine's local profile, runs **19 host jobs** (simulation only), and builds the USB unlock package without staging it.
Look for `All 19 local-profile host jobs matched expectations`. If the generator refuses, **do not bypass it**; open an issue with the message.

## 7. Baseline benchmark (while still locked)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\build.ps1 -Card 3070 -VcVars "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat"
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\run-benchmark.ps1 -Card 3070
```

Expect roughly **FP16/BF16 ≈ 39, TF32 ≈ 18 TFLOPS**. Note the `benchmark\results\` folder name.

## 8. Stage the unlock

Same command as step 5 plus `-StageUnlock`.

## 9. Run it

Shut down → boot menu → USB. **Press nothing.** Expected: banner + 5 s Esc window (Esc = plain Windows) → `pre-release-cold-ss0 status=0x...` lines (**not an error**, just register values) → screen goes black → unlock → Windows boots without a reset.

Check `D:\RTX3090-UNLOCK\AUTO000000\REPORT.TXT` ends with `SS0=88888888 SS1=00000008` and `FINAL status=0 ... clean=1`, then:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\run-benchmark.ps1 -Card 3070
python .\benchmark\compare_results.py .\benchmark\results\BEFORE .\benchmark\results\AFTER --same-machine-confirmed
```

Expect **FP16/BF16 ≈ 73, TF32 ≈ 38 TFLOPS**.

## Recovery

- Black screen for more than 3 min, or a hang: hold the power button, remove the stick, boot normally. The GPU returns to stock because its firmware is never modified.
- **Never retry in the same power session.**
- Logs: `D:\RTX3090-UNLOCK\HLS*.TXT`, `AUTO*\REPORT.TXT`. Attach them to issues.

## Daily use

The unlock resets on reboot, sleep and power-off. After a couple of good runs, put the stick **first** in the BIOS boot order and leave it plugged in.
Rebuild the profile (from step 5) after a motherboard BIOS update, a GPU or slot change, or a Windows reinstall. NVIDIA driver updates are fine.
