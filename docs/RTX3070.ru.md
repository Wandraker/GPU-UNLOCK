# RTX 3070: анлок тензорных ядер под Windows, пошаговый гайд

[English](RTX3070.en.md) · [README](../README.md)

Гайд написан по реальному запуску на Zotac RTX 3070 + Gigabyte B460M. Займёт 1–2 часа, из них большая часть уходит на установку инструментов.

## 0. Подходит ли твоя машина

Нужно всё из списка:

| Что | Как проверить |
|---|---|
| **RTX 3070 с ID `2484`** | В PowerShell: `Get-PnpDevice -Class Display -PresentOnly \| Select InstanceId`. В строке должно быть `DEV_2484`. Версия LHR (`DEV_2488`) **не поддерживается**. |
| Одна видеокарта NVIDIA | Встроенная графика (iGPU) допускается, но не больше одной. |
| Загрузка UEFI, **CSM выключен** | BIOS → Boot. |
| **Secure Boot выключен** | BIOS → Boot. Или `msinfo32` → «Состояние безопасной загрузки». |
| Интерфейс видеокарты не управляет монитором через «склейку» (aggregate console) | Обычный ПК с монитором, подключённым к RTX, подходит. |
| Флешка, которую не жалко | Любая, отформатированная в **FAT32**. |

Если включён BitLocker, заранее сохрани ключ восстановления.

## 1. Установить инструменты

PowerShell (обычный, не от администратора; на запросы UAC отвечай «Да»):

```powershell
winget install --id LLVM.LLVM --version 20.1.8 --exact
winget install --id Microsoft.VisualStudio.2022.BuildTools --exact --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install --id Python.Python.3.13 --exact
winget install --id Git.Git --exact
wsl --install -d Ubuntu-24.04
```

LLVM должен быть **ровно 20.1.8**.

## 2. Скачать этот репозиторий

```powershell
git clone https://github.com/Wandraker/GPU-UNLOCK C:\gpu-unlock\GPU-UNLOCK
```

Ниже путь `C:\gpu-unlock` используется как пример.

## 3. Сгенерировать прошивку (в WSL)

Пять файлов прошивки NVIDIA распространять нельзя, поэтому каждый генерирует их сам из официального драйвера. Открой **Ubuntu** из меню Пуск и выполни:

```bash
sudo apt-get update && sudo apt-get install -y git make tar zstd curl
curl -LsSf https://astral.sh/uv/install.sh | sh && ~/.local/bin/uv python install 3.14
sudo ln -sf ~/.local/bin/python3.14 /usr/local/bin/python3.14

cd ~ && git clone https://github.com/Zagitta/gpu-unlock.git fw && cd fw
git checkout --detach 0ebdb1c6308b6a2072be5bf04513472942541956
make inputs firmware PYTHON=python3.14 INPUTS=~/fw/inputs ASSETS=~/fw/assets
mkdir -p /mnt/c/gpu-unlock/assets && cp ~/fw/assets/*.bin ~/fw/assets/NVIDIA-LICENSE /mnt/c/gpu-unlock/assets/
```

Скрипт скачает около 340 МБ с серверов NVIDIA и проверит всё по SHA-256. В `C:\gpu-unlock\assets` должно появиться 5 файлов `.bin`. Если хеш хоть одного не совпадёт, сборка дальше откажется работать, и это правильно.

## 4. Выключить быстрый запуск Windows

PowerShell **от администратора**:

```powershell
powercfg /h off
```

Fast Startup не даёт карте полностью обесточиться при выключении, а анлок работает только с «холодной» карты.

## 5. Проба (только чтение) — два захвата

Вставь флешку FAT32. Узнай её букву (дальше в примере это `D`) и GUID системного EFI-раздела:

```powershell
(Get-Partition | Where-Object IsSystem).Guid
```

> **Важно про PowerShell 5.1.** Скрипты из репозитория запускай отдельным процессом, как в примерах ниже (`powershell -File ...`).
> Если перенаправлять вывод через `2>&1` или `*>`, PowerShell 5.1 примет прогресс тестов Python за ошибку и остановит скрипт.

Подставь свой GUID и запусти:

```powershell
cd C:\gpu-unlock\GPU-UNLOCK
powershell -NoProfile -ExecutionPolicy Bypass -File .\research\profile\new-machine.ps1 -Drive D -WindowsEspGuid ТВОЙ-GUID -Assets C:\gpu-unlock\assets -Clang "C:\Program Files\LLVM\bin\clang.exe" -LldLink "C:\Program Files\LLVM\bin\lld-link.exe"
```

На флешку запишется **проба**. Она ничего не пишет в видеокарту: только читает конфигурацию и BIOS карты, сохраняет это на флешку и запускает Windows.

Сделай **два раза**:
1. «Завершение работы», **не** перезагрузка.
2. Включи ПК и вызови меню загрузки (Gigabyte: **F12**, ASUS: **F8**, MSI: **F11**). Выбери флешку `UEFI: ...`.
3. Дождись загрузки Windows.

## 6. Профиль, тесты, сборка

Запусти **ту же команду** ещё раз. Она:
- соберёт профиль под твою машину из двух захватов;
- прогонит **19 проверок** (симуляция, видеокарта в них не участвует);
- соберёт USB-пакет с анлоком. На флешку он пока **не** записывается.

В конце должно быть `All 19 local-profile host jobs matched expectations` и `Host tests passed and the USB unlock package is built`.
Если генератор отказал, он напишет причину. В этом случае **не обходи проверку**, а открой issue с этим текстом.

## 7. Бенчмарк «до»

Пока карта ещё заблокирована, сними замер. Без него потом не с чем будет сравнить.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\build.ps1 -Card 3070 -VcVars "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat"
powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\run-benchmark.ps1 -Card 3070
```

`setup.ps1` скачивает CUDA 12.6 (только нужные библиотеки) и проверяет хеши. Перед замером закрой игры, OBS, браузер с видео и Wallpaper Engine.
Должно получиться примерно **FP16 и BF16 около 39 TFLOPS, TF32 около 18**. Запомни имя папки из `benchmark\results\`.

## 8. Записать анлок на флешку

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\research\profile\new-machine.ps1 -Drive D -WindowsEspGuid ТВОЙ-GUID -Assets C:\gpu-unlock\assets -Clang "C:\Program Files\LLVM\bin\clang.exe" -LldLink "C:\Program Files\LLVM\bin\lld-link.exe" -StageUnlock
```

## 9. Запуск

1. «Завершение работы» → включить → меню загрузки → флешка.
2. **Ничего не нажимай.** Порядок такой:
   - надпись `SINGLE RTX HEADLESS UNLOCK RESEARCH` и 5 секунд, когда можно нажать **Esc** (Esc = обычная Windows без анлока);
   - строки вида `pre-release-cold-ss0 status=0x...`. **Это не ошибка**, программа просто показывает значение регистра;
   - экран гаснет. Это нормально;
   - анлок, затем загрузка Windows **без перезагрузки**. Экран может пару раз мигнуть.
3. В Windows открой `D:\RTX3090-UNLOCK\AUTO000000\REPORT.TXT`. В конце должно быть:
   ```
   post-FLR ... SS0=88888888 SS1=00000008
   FINAL status=0 stage=transaction attempted=1 driver_release=0 clean=1
   ```
4. Бенчмарк «после» и сравнение:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\benchmark\run-benchmark.ps1 -Card 3070
   python .\benchmark\compare_results.py .\benchmark\results\ПАПКА_ДО .\benchmark\results\ПАПКА_ПОСЛЕ --same-machine-confirmed
   ```
   Ожидаемо **FP16 и BF16 около 73 TFLOPS, TF32 около 38**.

## Если что-то пошло не так

- **Чёрный экран больше 3 минут или зависание:** держи кнопку питания, пока ПК не выключится. Вытащи флешку и включи ПК как обычно.
  Карта будет в заводском состоянии, потому что её прошивка не менялась.
- **Не пробуй повторно в ту же сессию питания.** Каждая попытка только после полного выключения.
- Windows не грузится даже без флешки (маловероятно): в меню загрузки выбери `Windows Boot Manager` или поставь его первым в BIOS.
- Логи лежат на флешке: `D:\RTX3090-UNLOCK\HLS*.TXT` и `AUTO*\REPORT.TXT`. Приложи их к issue.

## Как пользоваться каждый день

- Анлок сбрасывается при **перезагрузке, сне и выключении**. Нужна холодная загрузка с флешки.
- Чтобы не вызывать меню загрузки каждый раз: после пары удачных запусков поставь флешку **первой** в порядке загрузки в BIOS и оставь её в ПК (удобно нано-флешку).
  Вынул флешку, и ПК грузит обычную Windows без анлока.
- После **обновления BIOS материнки**, замены карты, переноса её в другой слот или переустановки Windows профиль нужно собрать заново, начиная с шага 5.
  Обновление драйвера NVIDIA профиль не ломает.
